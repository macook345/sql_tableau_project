# Music Sales Analysis — SQL + Tableau Project

This project explores music sales data using SQL for extraction and Tableau for visualization. The goal was to derive insights into artist performance, genre popularity, and monthly sales trends using a structured, reproducible workflow.

---

##  Project Overview

- **Data Source**: Chinook database (music store sample dataset)
- **SQL Tool**: DBeaver with SQLite
- **Visualization Tool**: Tableau Public
- **Objective**: Analyze and visualize sales data to answer business-relevant questions

---

## Key Insights

- **Top Countries**: Identified top 5 countries by revenue
- **Genre Grouping**: Combined minor genres under “Other” for clean visual analysis
- **Sales Trends**: Analyzed monthly sales to understand customer behavior over time
- **Top Artists**: Identified top 10 artists by all-time revenue
---


## Tools & Skills Used

- **SQL** (joins, aggregations, filtering, grouping)
- **Tableau Public** (bar charts, trend lines, calculated fields, grouping)
- **DBeaver** for running queries and exporting CSVs

---

## How to Use

1. **SQL**: All query scripts are saved under `sql/` — these can be run using any SQLite-compatible interface.
2. **Data**: Exported query results are in `data/`, ready to be connected to Tableau.
3. **Dashboard**: Open the `.twbx` files in Tableau Public to view interactive dashboards.

---

## Notes

- Data was cleaned and aggregated before visualization.
- Minor categories were grouped in Tableau using calculated fields.
- Queries were tested for syntax and output consistency.
